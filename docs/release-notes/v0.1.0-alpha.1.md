# Resonance v0.1.0-alpha.1

The first source snapshot of Resonance: an offline SwiftUI client next to a
modular Fastify/Prisma server. It ships no signed app, hosted service, live
university OIDC integration, production storage, or support commitment.

## What is in this snapshot

- The iOS target is organized as `App`, `Core`, `Features`, and `SharedUI`.
- The server is one monolith with `app`, `platform`, and explicit identity,
  courses, entries, media, reviews, and sync modules.
- Versioned reads and media/session operations use `/api/v1`.
- `POST /api/v1/sync/commands` is the only external resource-mutation endpoint;
  the older unversioned routes are gone.
- OIDC identity mapping is issuer-scoped through `ExternalIdentity`, and
  persisted login attempts bind state, nonce, PKCE verifier, and browser
  context.
- Native app PKCE ties `app_code_challenge` to the later `codeVerifier` and the
  exact app callback, separately from the browser-to-IdP flow.
- Artifact sessions bind padded-base64 SHA-256, content type, and byte length;
  completion validates bounded ISO-BMFF M4A/MP4 evidence before publication.

## What it does not prove

[Development](../DEVELOPMENT.md) covers local setup and verification. Passing a
local source check does not establish production deployment, institutional
privacy operations, backup and retention practice, device distribution, or a
live identity-provider integration.
