# Support

Resonance is a source-only project for contributors and evaluators. It does not
include a hosted service, production SSO integration, deployment support, or a
support SLA.

For setup and verification, start with the [README](README.md) and the
[development guide](docs/DEVELOPMENT.md). The [architecture](docs/ARCHITECTURE.md)
and [API reference](docs/API.md) describe the current contracts. File
reproducible bugs or documentation issues with the repository issue templates,
and report security problems privately through [SECURITY.md](SECURITY.md).

Never attach private media, credentials, tokens, signed URLs, or real student
data to an issue.
